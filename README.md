# studio-os.de - Portfolio & Digital Studio

Official website for **studio-os / OUTLINES SHAPES** (3D Planning, Surveying/Vermessung, BIM, and CAD Services).

## Tech Stack

Built with [Astro](https://astro.build/), [Tailwind CSS](https://tailwindcss.com/), and [Tailus UI](https://tailus.io/).

## Development

### Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start local development server:**
   ```bash
   npm run dev
   ```
   This will start a local preview of the site.

3. **Build for production:**
   ```bash
   npm run build
   ```
